Love Connect Ultimate

O app privado do casal · v1.0 · Android 7.0+

⬇ Baixar o app (APK · 5,4 MB)

Se o botão não baixar, procure o arquivo love-connect-ultimate.apk na pasta Download.

📲 Como instalar

  1. Toque em Baixar o app acima.
  2. Abra o arquivo love-connect-ultimate.apk (pasta Download).
  3. Se o Android perguntar, permita “instalar apps desconhecidos”.
  4. Toque em Instalar e depois em Abrir 💕
🔒 Assinatura de teste (debug): o Android pode mostrar um aviso de “app desconhecido”. É normal — o app foi gerado por nós e não coleta nenhum dado.

✨ O que tem dentro

💬 Chat privado do casal
📸 Galeria de memórias
📅 Agenda + lembretes
⏳ Contador de dias juntos
🎮 5 jogos a dois
🎡 Roleta de encontros
💌 Cartas programadas
💰 Despesas divididas

💻 Prefere usar no navegador?

  • Abra a pasta do projeto e rode npm install && npm run dev, ou
  • Publique a pasta dist/ em qualquer hospedagem e instale como PWA (“Adicionar à tela inicial”).
